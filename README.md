# Automated HR Attrition Analysis & Reporting 🚀

An end-to-end Data Analysis project built using Python to analyze employee attrition trends, automate reporting, and generate professional visual insights for better decision-making.

## Tools & Libraries Used 🛠️
* **Python**
* **Pandas** (Data Cleaning & Automated Report Generation)
* **Matplotlib & Seaborn** (Advanced Data Visualization)

## Key Insights Discovered 📊
1. **Sales Department:** Experiences the highest attrition rate at **20.63%**.
2. **Monthly Income:** Lower-income brackets show a significantly higher tendency for employee attrition.
3. **OverTime:** Employees working overtime are much more likely to leave the company compared to others.
